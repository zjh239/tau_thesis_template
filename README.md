# Typst template for Tampere University doctoral thesis
Typst template for Tampere University doctoral thesis, personal developed.

The official one provided by the University is converted from the even older LaTex template I believe, which I think is overly designed and hard to use. So I wrote this myself.

I like providing the light-weight raw code for more transparency, that's why this is not uploaded to the Typst Universe.

== Instruction of using (asked from Hossein)

+ Install Typst (https://typst.app/) or using the webpage version (https://typst.app/)
+ Download this package
+ Go to the folder and compile using
```bash
typst compile main.typ
```
+ All the files are editable. Read the compiled PDF for more details.
